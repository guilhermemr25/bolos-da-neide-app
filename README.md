# Bolos da Neide
**Qual é o cliente deste repositório específico?**\
A confeiteira Neide.

**Qual o objetivo do sistema dele?**\
Um sistema para controlar pedidos em sua confeitaria.

**CLIENTE:** 1 cliente para N pedidos (1:N).\
**PEDIDOS:** N pedidos para 1 bolo (1:N).
